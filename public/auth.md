# Agent Authentication

Muhammad Rafiq's public portfolio does not require authentication for public browsing, indexing, or read-only agent discovery.

Public agents may access the homepage, about page, portfolio index, published case studies, contact page, robots.txt, sitemap.xml, and public discovery metadata.

No private APIs, admin routes, source credentials, CRM records, alumni databases, deployment credentials, analytics credentials, or unpublished project materials are available to agents through this site.

If authentication is introduced later, this document should be updated with the supported authorization flow, scopes, token endpoint, and protected resource metadata.
